# KeePassXC key-file fixtures

KDBX 4 databases whose key file was set by KeePassXC 2.8.0 (`brew install --cask keepassxc`). `keepassxc-cli db-create`
writes KDBX 3.1, which PasswordPie does not open, so each database started as an empty KDBX 4 file (Argon2id, 1 MiB,
2 passes, password `pie-test`) and KeePassXC then set the key file, re-encrypted it, and added the entry. The composite
key in every file was computed by KeePassXC.

Password `pie-test`, except `keyfile-only.kdbx`, which has none. Each holds one entry, `Example <name>`, username
`ada`, password `hunter2-<name>`.

| Database | Key file | Format |
|---|---|---|
| `v2.kdbx` | `v2.keyx` | KeePass XML 2.0, generated by KeePassXC |
| `v1.kdbx` | `v1.key` | KeePass XML 1.0 (Base64) |
| `binary32.kdbx` | `binary32.key` | exactly 32 bytes |
| `hex64.kdbx` | `hex64.key` | 64 hexadecimal characters |
| `any.kdbx` | `any.key` | any other file: SHA-256 of its contents |
| `keyfile-only.kdbx` | `v2.keyx` | no password, key file only |

    echo pie-test | keepassxc-cli db-edit -q --set-key-file v2.keyx v2.kdbx
    printf 'pie-test\nhunter2-v2\n' | keepassxc-cli add -q -k v2.keyx -u ada --url https://example.com -p v2.kdbx 'Example v2'
    echo pie-test | keepassxc-cli db-edit -q --set-key-file v2.keyx --unset-password keyfile-only.kdbx
    printf 'hunter2-keyfile-only\n' | keepassxc-cli add -q --no-password -k v2.keyx -u ada --url https://example.com -p keyfile-only.kdbx 'Example keyfile-only'

`v2.keyx` came from `keepassxc-cli db-create --set-key-file`, which writes a new key file when the path does not exist.
