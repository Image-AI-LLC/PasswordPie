Overview

A door, then a menu

Locked: a 300 × 280 pt brushed-grey door with a dial on the seam. Unlocked: the same window becomes a native menu with cascading submenus and a details popover.

A menu, not a window

21 pt rows, 14 pt text, a flat selection fill, and the keyboard stays in the search field. Width and height follow the rows.

Native, not themed

System font, SF Symbols, the menu material and semantic colours, so the menu follows light and dark. The door stays light; brand graphite stays outside the panel.

Colors

Menu colours are system colours resolved on macOS 27 with the default blue accent; -dark tokens are the dark appearance. menu-material is a preview stand-in for the system menu material. Translucent values are shown over a checkerboard.

Text tokens use weights 400, 500 and 600; line height is the font default (1.18). Glyphs are not type tokens: SF Symbols are 8, 13, 15, 16 and 19 pt (Touch ID light), and the submenu arrow is a drawn 8.5 × 10 pt triangle.

Typography — CJK 中文

System cascade to PingFang SC. Same sizes; line height +0.1; tracking 0; minimum 10 pt; no synthetic bold or italic. Group headers are upper-cased in code; CJK has no case.
